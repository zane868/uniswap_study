# AMM 常见问题

## 1. 什么是 AMM？它和订单簿模式有什么区别？

AMM：自动化做市商。

AMM 与订单簿的核心区别：

| 对比维度 | AMM | 订单簿 |
| --- | --- | --- |
| 流动性 | 依赖 LP 提供流动性 | 依赖做市商 |
| 价格 | 根据池子储备和 `x * y = k` 计算 | 买卖双方自行报价，系统撮合 |
| 收益 | 通过手续费实现收益 | 通过价差实现收益 |

## 2. AMM 的核心算法是什么？

`x * y = k`。

## 3. 什么是滑点？用户交易时如何避免滑点过高？

滑点是提交交易和最终成交之间的差异。

避免滑点过高的方法：

- 少量多次交易。
- 避开价格波动。
- 选择流动性充足的交易路径。
- 设置最低接收量。

## 4. 什么是三明治攻击？如何降低被三明治攻击的风险？

### 三明治攻击示例

假定攻击方为 A，实际买方为 B，池子储备为 10 ETH 和 100 USDT，恒定乘积为 1000。

1. B 计划用 10 USDT 购买 ETH，并提交交易 T1，预期可收到 0.9091 ETH。

   ```text
   1000 / (100 + 10) ≈ 9.0909
   10 - 9.0909 ≈ 0.9091 ETH
   ```

2. A 观察到交易 T1，创建交易 T2。因为 T1 没有落到链上，T2 的系统报价和 T1 一致。A 设法让 T2 先于 T1 落到链上，用 10 USDT 买到 0.9091 ETH。

3. T1 开始落链。在实际执行合约时，池子已经变成了 9.0909 ETH 和 110 USDT。

   ```text
   1000 / (110 + 10) ≈ 8.3333
   9.0909 - 8.3333 ≈ 0.7576 ETH
   ```

   没有有效的最低接收量保护，B 实际只能收到 0.7576 ETH，比预期少了 0.1515 ETH，少收到约 16.67% 的 ETH。

4. A 观察到 T1 落链完成，开始换回 USDT，创建交易 T3。此时池子是 8.333 ETH 和 120 USDT，A 最终获利 1.8033 USDT。

   ```text
   1000 / (8.3333 + 0.9091) ≈ 108.197
   120 - 108.197 ≈ 11.8029 USDT
   ```

### 降低风险

设置合理的滑点。在公链上，风险只能相对降低，很难绝对避免。

## 5. LP 的作用是什么？

保障流动性。

## 6. 什么是无常损失？如何计算？

无常损失：提供流动性带来的收益少于直接持有的收益。

### 初始持有

- 持有资产：10 ETH、1000 USDT。
- 初始价格：1 ETH = 100 美元，1 USDT = 1 美元。
- 总价值：`10 * 100 + 1000 * 1 = 2000 美元`。

做 LP 放入池子：`10 ETH * 1000 USDT = 10000`。

### ETH 市价涨到 200 美元

直接持币价值：`10 * 200 + 1000 * 1 = 3000 美元`。

恒定乘积关系：

```text
x * y = k
y = k / x
x = k / y
k = 10000
```
无常损失的计算：以直接持币的 3000 美元为基准，损失金额 = 3000 − 池中资产总价值，损失占比 = 损失金额 / 3000。以下金额保留四位小数，占比保留两位小数。

| 池中 ETH | 池中 USDT | 按 ETH 市价 200 美元计算总价值 | 无常损失金额（美元） | 无常损失占比 | 备注 |
| ---: | ---: | --- | ---: | ---: | --- |
| 10 | 1000 | `10 * 200 + 1000 = 3000` | 0.0000 | 0.00% | |
| 9 | 1111.1111 | `9 * 200 + 1111.1111 = 2911.1111` | 88.8889 | 2.96% | |
| 8 | 1250 | `8 * 200 + 1250 = 2850` | 150.0000 | 5.00% | |
| 7.071068 | 1414.2136 | `7.071068 * 200 + 1414.2136 = 2828.4272` | 171.5728 | 5.72% | 平衡点 |
| 7 | 1428.5714 | `7 * 200 + 1428.5714 = 2828.5714` | 171.4286 | 5.71% | |
| 6 | 1666.6667 | `6 * 200 + 1666.6667 = 2866.6667` | 133.3333 | 4.44% | |
| 5 | 2000 | `5 * 200 + 2000 = 3000` | 0.0000 | 0.00% | |

表中展示不同储备组合按同一外部价格估值时的差额；只有标注的平衡点满足池内报价等于 200 USDT/ETH。平衡点行采用已四舍五入的表内数值，精确计算见下文。

### 平衡点

假设没有手续费，也没有添加或撤出流动性，且套利已使池内报价等于外部市场价格。

变量定义：

- $x_0$、$y_0$：初始 ETH 和 USDT 数量。
- $k=x_0y_0$：恒定乘积。
- $P$：外部市场价格，单位为 USDT/ETH。
- $x$、$y$：平衡点时池中剩余的 ETH 和 USDT 数量。

平衡点同时满足：

$$
xy=k,\qquad \frac{y}{x}=P
$$

由 $y=Px$ 代入恒定乘积公式：

$$
x\times Px=k
\quad\Rightarrow\quad
x^2=\frac{k}{P}
$$

资产数量为正，因此取正平方根，得到平衡点公式：

$$
\boxed{x=\sqrt{\frac{k}{P}}}
$$

代入本例的 $k=10000$、$P=200$：

```text
x = √(10000 / 200) ≈ 7.071068 ETH
y = 10000 / x ≈ 1414.213562 USDT
池内报价：y / x = 200 USDT/ETH
```

平衡点由实际交易形成；外部价格变化本身不会自动改变池子的储备或报价。
